What this means

Both recommended-sample-size metrics track the original study's n_per_item strongly and positively (pooled: precision ρ ≈ –, reliability ρ ≈ –), and the relationship holds within every one of the six variables individually (see per-panel ρ above) — it isn't driven by one outlier variable. Correlation with n_items (word count) is weak-to-negligible by comparison. The asymptotic reliability the simulation reaches at its largest tested sample size is only weakly related to the original n (ρ ≈ –) — so the original sample size mostly shifts how much n you need to get there, not the ceiling reliability itself.

Practically: a dataset's simulated recommendation is partly an artifact of how many raters the original study happened to use, since that count sets the observed item SDs the simulation samples from (smaller original n → noisier point-estimate of each item's SD → simulation compensates with a larger recommended n, and vice versa). Pooling across all these runs to get one "recommended n" folds in that dependency rather than removing it — a dataset run from a small original study isn't necessarily telling you your own norming study will need a large n; it may just be telling you its own SD estimates were noisy.
